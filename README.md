# 🌟 Himesh Time — Personal Daily Routine & Task Planner

A 100% offline-first Progressive Web App (PWA) designed and built specifically for Himesh Bhai. Installable on Android & desktop as a standalone app.

---

## ✨ Features

### 1. 🎯 Daily Goal Section (With Time/Deadline)
- Set your **#1 key goal** for each day.
- **Target time / deadline picker** (e.g. `17:00` → `5:00 PM`).
- Big satisfying checkmark completion toggle with audio/visual feedback.

### 2. 📋 12 Pre-Configured Daily Habit Templates (Pure Checklist, No Time)
Auto-populates every day automatically at midnight / app launch:
- **🙏 Spiritual & Routine:**
  - Aarti (Morning & Evening)
  - Morning Pooja
  - Vachan Amrut
  - Swamini Vato
  - Chesta (Night)
  - My Diary (Night reflection)
- **📚 Learning & Skill Building:**
  - Duolingo Practice
  - GATE Prep / Study Block
  - Book Reading
- **💼 Career & Projects:**
  - Internship Work
  - Startup Work

### 3. ⚡ Dynamic & Temporary Task Support
- **Floating Action Button (FAB)** on the home screen.
- Create quick one-time tasks for "Today".
- Tagged with a distinct violet **`⚡ [Temporary]`** badge so they stand out from recurring habits.
- Option to toggle "Repeat Daily" to save as a permanent recurring template.

### 4. 📊 Live Progress Ring & Celebrations
- Circular animated SVG progress ring.
- Real-time completed fraction (e.g. `9/12 Done`).
- Dynamic motivational quotes that adapt as you complete tasks.
- **Confetti animation** whenever you reach 100% completion!

### 5. ⚙️ Settings & Offline Backup
- **Customize Name** (default: Himesh).
- **Dark / Light Theme** switcher with glassmorphism design.
- **Reset Templates** to default 12 habits anytime.
- **JSON Export & Backup** of all tasks, history, and goals.
- **Wipe / Reset** database safely.

## 🚀 How to Run & Install on Android

### Quick Launch on PC
Double-click `Start-App.bat` or run:
```bash
npx serve -l 3000 .
```
It will open `http://localhost:3000` in your browser.

### Install on Android Phone (as Native App)
1. Ensure your phone and PC are on the same Wi-Fi network (or host the folder on GitHub Pages / Cloudflare Pages / Vercel for free).
2. Open the URL in **Google Chrome** on your Android phone.
3. Tap the **three dots menu (⋮)** in Chrome and select **"Add to Home screen"** or **"Install app"**.
4. **"Himesh Time"** will now appear on your home screen and app drawer with its custom icon.
5. It works **100% offline** without any internet connection needed!
